# Transpence

**Transpence** — фронтенд застосунку для персонального фінансового обліку. Проєкт допомагає відстежувати доходи й витрати, імпортувати операції з Excel-файлів, аналізувати статистику за періодами та керувати кредитами.

## Можливості

- **Реєстрація та авторизація** користувачів із token-based authentication.
- **Імпорт фінансових операцій** з `.xlsx` файлів.
- **Дашборд операцій** з фільтрами та пошуком.
- **Візуалізація статистики** через графіки.
- **Порівняння періодів** (місяць/рік).
- **Профіль користувача** зі статистикою та файлами.
- **Кредити**: створення та управління позиками.
- **Адаптивний UI** з модалками та анімаціями.
